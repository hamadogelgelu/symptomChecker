Project Overview

This is a personal project designed to explore how APIs can be applied in the medical field. The website allows users to input personal information and describe any symptoms they are experiencing. After submitting your information, click the button at the bottom of the page to view potential illnesses based on the symptoms provided.

Disclaimer: This is not an official symptom checker and should not be used for medical advice.

Getting Started

Create an OpenAI API Key

Go to https://platform.openai.com and create an account.

Once logged in, select “View API Keys” and click “+ Create new secret key.”

Copy your API key and store it securely.

Set up the Project

Open the server.js file.

Replace process.env.OPENAI_KEY on line 13 with your API key.

Run the Project Locally

Start the server by running server.js on a local server.

Open index.html using a live server to access the website.
